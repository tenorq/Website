## 🏗️ About This Repository

This repository contains the source code for the Tenorq website.

It is built to reflect our engineering principles:

- Clean structure
- Reusable components
- Minimal, intentional design
- Performance-focused implementation

---

## ⚙️ Tech Stack

- **Next.js (App Router)**
- **Tailwind CSS (design system via CSS variables)**
- **TypeScript**
- **Geist Font (Next.js font optimization)**

---

## ✨ Key Characteristics

- Fully responsive across devices
- System-driven theming (light/dark aware)
- Full-screen hero with scroll-based transitions
- Layered UI structure (hero → content flow)
- Brand-driven design system
- Clean, minimal, high-signal interface

## 🚀 Running Locally

```bash

```
